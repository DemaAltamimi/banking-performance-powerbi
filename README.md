# Banking Performance & Customer Analytics

## Project Overview
An interactive Banking Performance and Customer Analytics dashboard developed using Microsoft Power BI.

This project analyzes banking transactions, customer information, and branch performance to help management monitor financial activities and gain useful business insights.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Pages

### 1. Banking Overview
- Total Customers
- Total Transactions
- Total Deposits
- Net Cash Flow
- Monthly Transaction Amount
- Deposits vs. Withdrawals by Branch
- Transactions by Type
- Interactive Date and Branch slicers

### 2. Transactions Analysis
- Total Transaction Amount
- Average Transaction Amount
- Completion Rate
- Monthly Deposits vs. Withdrawals
- Transactions by Channel
- Transactions by Status
- Completed Transaction Amount by Branch
- Interactive Transaction Type, Channel, and Date slicers

### 3. Customers & Branches
- Total Customers
- Customers with Transactions
- Total Transactions
- Customers by City
- Customers by Account Type
- Customers by Age Group
- Transactions by Branch
- Interactive City and Account Type slicers

## Key Features
- Interactive report pages and slicers
- DAX measures for financial and customer analysis
- Completed transactions used for financial amount calculations
- Transfers excluded from Net Cash Flow
- Custom report page tooltips
- Interactive page navigation

## Financial Calculation Rules
Financial calculations include completed transactions only. Net Cash Flow is calculated as Total Deposits minus Total Withdrawals, excluding transfers.
